# OTSO

![OTSO Logo](assets/OTSO_logo.png)

OTSO is a tool used for trajectory computations of charged particles in the Earth's magnetosphere.

OTSO is designed to be open-source; all suggestions for improvement are welcome, and please report any bugs you find. I welcome any help provided by the community in the development of OTSO.

# Supported Platforms
OTSO supports Python 3.11 to 3.15 on:

- Linux (x86_64 and ARM64)
- Windows (x86_64)
- macOS on Apple Silicon (M1 or later)

Intel Macs are not supported: the prebuilt Fortran libraries for macOS are Apple Silicon only. On macOS, install the gcc runtime with `brew install gcc`.
